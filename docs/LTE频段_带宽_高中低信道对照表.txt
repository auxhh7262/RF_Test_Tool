LTE 频段 / 支持带宽 / 低·中·高信道 对照表
==============================================================================
数据来源 : specs/LTE\bands.json（本目录本地快照）
           RF Band Tool，3GPP R19 / TS 36.101，共 73 个 LTE 频段
算法来源 : TS 36.101 5.7.3 / 本脚本 hml()
           lo = max(n_offs + B*5, n_min)
           hi = min(n_max - B*5 + 1, n_max)
           mid = (lo + hi) // 2     [B*5 = (B/2)/0.1MHz，信道须整条落在频段内]
校验     : 已按频段频率边界逐点验证 239 个 频段×带宽 组合的低/中/高信道，全部通过

命名约定 : 界面显示 频段 B1/B2/…/B111，带宽 1.4MHz/3MHz/5MHz/10MHz/15MHz/20MHz
           CMW500 SCPI 内部仍用 CONF:LTE:SIGN:BAND OB<n> 与
           CONF:LTE:SIGN:CELL:BAND:DL B0xx（仪表只接受此写法，见下表对照）

本工具可用频段 : 63 个（其余 10 个见文末说明）
频段×带宽组合 : 239 个，每组合测 低/中/高 三个 DL EARFCN（重合时去重）
界面用法   : 工具中每个频段一行，只能勾选该频段支持的带宽（不支持显示 — ）；
           测试项 = 各频段自己勾选的带宽，不做全局频段×带宽笛卡尔积。
           勾选频段默认只勾 10MHz；不支持 10MHz 的频段默认取最接近的支持带宽。
           批量：先勾多个频段，再点表头带宽复选框即可整列一次生效。
注意       : 各频段只测其支持的带宽；不支持的组合自动跳过，不下发非法信道。
           高位频段能否由 CMW500 建立小区，以仪表固件/LTE 信令选件为准。
